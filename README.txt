Digonto Sheets 1.0
==================
A spreadsheet in the style of Excel, Google Sheets and LibreOffice Calc.

Grid with 1,048,576 rows x 16,384 columns (stored sparsely, so it stays fast), formula bar with function suggestions and
point-and-click references, 200+ functions (math, text, date, logic, lookup incl. XLOOKUP, statistics, finance, arrays like
FILTER / SORT / UNIQUE / SEQUENCE), number formats, fonts, colors, borders, merge, wrap, freeze panes, conditional formatting,
sort and filter, find and replace, fill handle and series, named ranges, multiple sheets, charts (bar, line, pie, scatter), zoom.
Files: XLSX (open/save), CSV/TSV, PDF export.

Limits in this version: charts are not saved inside XLSX yet (the app warns you); macros are not supported.
Tested here without a real screen; please report bugs after your own testing.
Only PySide6-Essentials is installed, locked with SHA-256 hashes.

Data validation (Data > Data validation): list, whole number, decimal, date, text length, custom formula; dropdown arrow, input message, stop / warning / information alerts; saved in XLSX.

Start screen: opens with New / Open on the left and your recent files on the right. Open has tabs (This computer, Recent, Shortcuts). Ctrl+W returns to the start screen; the program asks before closing a workbook with unsaved changes.
